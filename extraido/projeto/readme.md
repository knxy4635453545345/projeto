# HELLBORN native

Cheat nativo Android para Roblox (arm64-v8a). Injeção externa via AndKittyInjector.

## Dependências

- Android NDK r26+
- CMake 3.22+
- submodules:
  - third_party/imgui  → github.com/ocornut/imgui (branch docking)
  - third_party/Dobby  → github.com/jmpews/Dobby

```bash
git submodule add https://github.com/ocornut/imgui third_party/imgui
git submodule add https://github.com/jmpews/Dobby  third_party/Dobby
